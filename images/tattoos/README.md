# My Work / hotové tetovania

Nové fotky hotových tetovaní pridávaj priamo do tohto priečinka (`images/tattoos`).

- Na GitHube otvor `images/tattoos`.
- Klikni na **Add file → Upload files**.
- Nahraj fotky a potvrď **Commit changes**.
- Použi súbory JPG, JPEG, PNG, WEBP, GIF alebo AVIF.
- Fotky sa na webe načítajú automaticky z GitHubu; netreba upravovať `index.html`.
- Názvy súborov určujú poradie abecedne (napr. `01.jpg`, `02.jpg`, `03.jpg`).
- Kliknutie na fotku otvorí tvoj Instagram `@tragedia.png`.

Odporúčanie: používaj krátke názvy bez diakritiky a optimalizované fotky, aby sa web rýchlo načítal.
