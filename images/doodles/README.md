# Doodles

The current doodles stay as they are by default. To add your own, upload JPG, JPEG, PNG, WEBP, GIF, or AVIF files directly into this folder. On mobile, new doodles are randomly used in some spots, while the remaining spots keep existing doodles.

You can delete any old doodle files from this folder; the website will use only the images that are still here. Keep `kvet.png` in the folder for the flower, which stays fixed in its current position.

Use clear filenames and optimized images for faster loading.
