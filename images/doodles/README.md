# Mobile doodles

Add or remove JPG, JPEG, PNG, WEBP, GIF, or AVIF images in this folder to change the mobile doodle choices. The site randomly selects from these files on mobile and gives each doodle a modest size in the free space above or below section content.

Keep `kvet.png` in this folder for the flower in the hero; it stays fixed in its current position. Use clear filenames and optimized images for faster loading.
