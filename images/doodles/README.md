# Doodles

The current doodles stay as they are by default. To add your own, upload JPG, JPEG, PNG, WEBP, GIF, or AVIF files directly into this folder. On mobile, newly added files are randomly used in some doodle spots; the existing doodles remain in the other spots.

The flower doodle stays fixed in its current position. Use clear filenames and optimized images for faster loading.
